
# Kajun Cowboy Kitchen Weather

A weather website for my Kajun Cowboy Kitchen food truck in New Orleans, Louisiana.

Click the Check the weather button to see live weather information.

## Endpoint

https://api.open-meteo.com/v1/forecast

API: Open-Meteo
Method: GET

## What I changed using the docs

I added `wind_speed_unit=mph` to my weather API request.

Before: 6.2 km/h

After: 2.5 mph

This change displays wind speed in miles per hour instead of kilometers per hour.
